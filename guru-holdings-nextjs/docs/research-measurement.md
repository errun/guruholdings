# 研究功能观察点

日期：2026-11-02。目标：判断目标访客是否更愿意研究机构与股票，并继续浏览、回访。

## 实现范围

沿用现有 GA4 G-Q0X5T11MVY；正式域名才加载 Google 统计。Vercel 预览、本机不加载统计，浏览器测试用隔离的 gtag 接收器核对事件，不向正式属性发送测试访问。

| 事件 | 时机与口径 |
| --- | --- |
| research_section_view | 搜索、比较、历史图表或季度表进入前台可视区域；每次页面浏览同一区域一次 |
| signal_view | 共同变仓卡片、单机构信号实际可见；每次浏览按类型、股票、机构去重 |
| signal_select | 用户从信号卡片点击股票或机构链接 |
| research_navigation | 正文中可信点击股票/机构站内链接；不把预取或程序导航计为点击 |
| search_results | 用户改变搜索/筛选且稳定600ms，或点击结果前；默认推荐列表不算用户搜索 |
| search_no_results | 上述稳定搜索的股票、机构、信号展示结果全部为空 |
| search_result_select | 在搜索区域点击股票、机构或信号结果 |
| compare_start | 首次主动改变机构选择；默认自动对比不算开始操作 |
| compare_results | 主动选择至少两家后呈现结果，记录展示的共同持仓/加减仓行数；不把它等同阅读完成 |
| compare_result_select | 点击比较区域的机构或股票结果，含默认结果 |
| history_quarter_change | 用户主动切换机构季度表的季度 |
| history_details_open | 打开股票历史/原始数据折叠区；关闭不算打开 |
| chart_interact | 图表内主动点击/触摸，或方向键等操作；每页每类图表一次，不把被动悬停算阅读 |

区域/卡片的曝光阈值为高度25%或200px（取较小值），由 IntersectionObserver 的离散阈值采样；不等同精确阅读，也不保证鼠标点击前已完成曝光采样。路由切换清理旧监听，后台标签页不发送自定义事件，BFCache恢复重新计算曝光。

自定义参数只允许公开实体标识、分类、布尔值和有上限的结果计数。搜索原文、邮件、密钥、用户标识、完整查询URL均不进入自定义事件。事件的page_location只保留origin与pathname。原有GA4自动页面/来源采集行为不在本次替换范围。

不创建自定义计时器，不填写engagement_time_msec，不把曝光设为关键事件。有效时长、初访/回访、设备和流量来源使用GA4原生指标。7天回访尚需用GA4留存口径观察，不能根据compare_results推算。

## 报表与分析

受保护的POST /api/seo/daily新增behavior字段，最近7天（到昨天）和前7天的13类事件按eventName汇总eventCount、totalUsers，日期采用GA4属性时区并在behavior.periods中单独注明，不沿用GSC终结数据的较长延迟。只读取本站两个正式主机名，复用两项Google只读授权，无需自定义维度。额外事件报告失败时behavior.status为unavailable并明确警告，保留原有GA4/GSC报告，禁止将读取失败当作零使用。

GA4实时/事件页可看事件总量。按股票、页面类型或语言细分自定义参数，需要另外在GA4后台注册相应自定义维度；这一步未自动执行，现有Google授权仅只读。尚无新的用户可见统计看板。本次也未启用每日云端调度。

第一次评估先验证页面访问与参与是否完整、流量异常来自哪里，再用搜索结果点击、研究跳转、历史查看、对比结果点击解释有效时长变化。曝光与点击是事件计数，跨事件不能直接相除当作精确的用户漏斗或因果提升。

## 验证与发布

本机验证结果：16项自动测试通过，150页生产构建通过；32个多语言页面和7832个sitemap URL检查通过；模拟授权HTTP边界200/403/303/400/401均符合预期。独立Chromium浏览器16个断言通过：4次指定站内点击恰好4次research_navigation，3次搜索/1次无结果，1次比较开始/2次结果更新，中英文季度切换2次；正式Google请求0、浏览器运行异常0。另用本机页面与Google脚本替身模拟正式域名，HTTP200、初始化1次、脚本加载1次，站内切换后仍观察到信号；这不是正式GA4入库验证。

- 自动检查：npm run analytics:test、npm run seo:cloud:test、npm run typecheck、npm run build、npm run seo:cloud:smoke、npm run seo:check。
- 浏览器：不操作时不报搜索/比较；查无结果、查股票、点击结果、股票到机构、换季度、比较、历史区、图表操作；确认事件去重和无搜索原文，预览不加载正式GA。
- 用户批准后才合并发布；上线后应实测浏览器到GA4 DebugView/实时及Data API的接收。未完成这个步骤前不能声称GA4已入库。
- 回退本PR即可移除新事件及behavior字段；Google授权、私有存储无需变更。

交付节奏：前3轮每隔一天，之后每周，每日观察。这个约定不代表云端定时任务已经启用。
