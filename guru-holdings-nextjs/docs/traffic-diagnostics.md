# 流量来源与采集完整性诊断

新增受现有管理员口令保护的 `POST /api/seo/daily?view=traffic`。沿用原Google只读授权，不增加账号权限、前台脚本、第三方服务或费用，不覆盖每日加密报告。原日报和实时验收模式保持原有用途。

七项固定聚合查询：总量、来源/媒介与渠道、来源/国家/设备、来源/入口路径、日期/来源、浏览器/系统/设备、事件/来源。仅正式域名，排除 `codex_` 测试来源，日期按GA4资源时区最近28天至昨天。入口路径不含查询字符串。不查询用户标识、IP、原始搜索词或完整网址。

最多并发三项，各表最多200行；单项失败保留其余结果，同时标明缺失；记录截断、阈值、抽样和other-row限制，不把缺失解释为零。不同维度或表格不可相加当成全站会话。查询没有机器人身份判定能力，结论须结合浏览器采集证据和可用托管请求聚合，不能仅凭桌面流量占比或国家判定机器人。

该模式返回管理员私有统计。公开仓库仅保存查询实现与虚构测试，不上传真实统计、Google凭据或管理员口令。

`view=traffic_remaining`沿用相同保护，但每项均固定排除“Direct来源 AND Singapore国家 AND desktop设备”的组合。排除通过单个NOT(AND)完成，不扩大成排除整个国家、所有桌面或所有直接访问。不接受任意查询参数或自定义Google条件，不删除原始数据。余量另有页面路径统计，事件带日期、地区设备表带新访/回访维度，总共八项固定查询，以便区分研究操作刚上线与历史流量。原模式仍提供总量；余量不是已验证真人，事件计数也不是会话转化率。
